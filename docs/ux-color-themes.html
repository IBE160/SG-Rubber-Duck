Color Theme

Primary blues for navigation/CTA, amber for emphasis, green/red for KPI states. Dark panels for contrast with Gantt/event logs.

Primary
#2b8fef / hover #0f6fcf
Accent
#f5b041 — highlights, KPIs
Success
#6bd48e — on-track signals
Danger
#f26b6b — risks/alerts
Panel
#121c33 — cards/panels
Background
#0e172a — app shell

Usage

  • Buttons/links: primary → primary-strong on hover, accent for secondary CTAs.
  • KPIs: success/danger for state chips; accent for “at risk”.
  • Charts: primary (bars/lines), accent (forecast), muted text for labels.
