# Visual Design Guidelines

This document outlines the color palette and typography for the AI-Driven Construction Project Management Simulator, based on the principles of a "clean, professional, and educational" theme and the Material-UI design system.

## 1. Color Palette

The color palette is designed to be professional, accessible, and visually pleasing. It consists of a primary color, a secondary color, and a set of neutral colors for text and backgrounds.

### Primary Color

*   **Blue:** A professional and trustworthy blue will be used as the primary color for branding elements, buttons, and links.
    *   **Primary Main:** `#1976D2` (A standard Material-UI blue)
    *   **Primary Light:** `#42A5F5`
    *   **Primary Dark:** `#1565C0`

### Secondary Color

*   **Amber:** A warm amber will be used for accents and to draw attention to secondary actions.
    *   **Secondary Main:** `#FFC107` (A standard Material-UI amber)
    *   **Secondary Light:** `#FFD54F`
    *   **Secondary Dark:** `#FFB300`

### Semantic Colors

*   **Error:** `#D32F2F` (Red for errors and critical alerts)
*   **Warning:** `#FFA000` (Orange for warnings)
*   **Info:** `#0288D1` (Light blue for informational messages)
*   **Success:** `#388E3C` (Green for success states and positive feedback)

### Neutral Colors

*   **Background:**
    *   **Default:** `#FFFFFF` (White)
    *   **Paper:** `#F5F5F5` (A very light gray for cards and paper-like surfaces)
*   **Text:**
    *   **Primary:** `#212121` (A dark gray for main text)
    *   **Secondary:** `#757575` (A lighter gray for secondary text)
*   **Divider:** `#E0E0E0` (A light gray for dividers)

## 2. Typography

The typography will be clean, legible, and modern, using a standard sans-serif font that is widely available and works well for UI design.

### Font Family

*   **Primary Font:** `Roboto`, as it is the default font for Material-UI and is designed for readability on screens.
*   **Fallback:** `Helvetica`, `Arial`, `sans-serif`.

### Font Sizes

*   **h1 (Headline 1):** 32px
*   **h2 (Headline 2):** 28px
*   **h3 (Headline 3):** 24px
*   **h4 (Headline 4):** 20px
*   **h5 (Headline 5):** 18px
*   **h6 (Headline 6):** 16px
*   **Subtitle 1:** 16px
*   **Subtitle 2:** 14px
*   **Body 1 (Main text):** 16px
*   **Body 2 (Secondary text):** 14px
*   **Button:** 14px
*   **Caption:** 12px

### Font Weights

*   **Light:** 300
*   **Regular:** 400
*   **Medium:** 500
*   **Bold:** 700

---

## 3. Application in UI

*   **Buttons:** Primary buttons will use the `primary.main` color, and secondary buttons will use the `secondary.main` color.
*   **Charts and Graphs:** The color palette will be used to create clear and readable charts. The primary and secondary colors will be used for the main data series, and the semantic colors will be used to highlight important information (e.g., a red line for a budget overrun).
*   **Text:** The dark gray `text.primary` will be used for most text to ensure high contrast and readability. `text.secondary` will be used for less important information.
