# Preliminary Design Summary for ibe160

This document summarizes the initial UX design understanding and key decisions made for the "AI-Driven Construction Project Management Simulator" (ibe160).

---

## 1. Project Overview

The **AI-Driven Construction Project Management Simulator** is an educational web platform designed to transform how project management is taught. It provides an interactive environment where students and new professionals can design, execute, and analyze simulated construction projects.

The core of the experience is a seamless flow from **effortless data input** during the project setup phase to **clear, engaging visualizations** of real-time simulation results. By combining classical project management algorithms with an AI-powered feedback loop, the simulator makes the complex consequences of planning decisions visible and understandable.

Our primary users are **construction management students**, with secondary audiences including instructors and trainee project managers. The user experience will be engineered to make them feel **efficient, productive, and in complete control**, fostering a sense of mastery and confidence.

---

## 2. Design System Choice

After evaluating various options, the chosen design system for ibe160 is **Material-UI (MUI)**.

**Rationale:**
MUI was selected because it aligns perfectly with the project's vision for a professional, clean, and educational user experience. Its comprehensive component library is well-suited for building data-heavy applications, dashboards, and forms, which are critical for the simulator's input and analysis phases. This choice will ensure a high-quality, consistent, and trustworthy feel for the application, supporting the desired emotional response of users feeling "efficient, productive, and in control."
