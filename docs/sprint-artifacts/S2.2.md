# Story S2.2: Create WebSocket Endpoint for Simulation Event Streaming

## Epic
E2: Simulation Engine & Real-time

## Description
As a frontend developer,
I want a WebSocket endpoint to receive real-time simulation events,
So that I can display live updates of simulation progress without polling.

## Technical Details

### WebSocket Implementation
- Built using FastAPI's native WebSocket support
- No external dependencies required (websockets already included)
- Async/await pattern for efficient connection handling

### Components

**ConnectionManager Class:**
- Manages active WebSocket connections per simulation
- `connect()` - Register new connection
- `disconnect()` - Remove connection
- `broadcast()` - Send message to all clients for a simulation

**Endpoints:**

1. **WebSocket: /ws/simulations/{simulation_id}/events**
   - Client connects: `ws://localhost:8001/ws/simulations/{simulation_id}/events`
   - Receives real-time simulation events
   - Supports ping/pong keep-alive mechanism
   - Auto-sends last 50 events on subscription

2. **POST /simulations/{simulation_id}/broadcast-event/**
   - Simulation engine sends events via HTTP
   - Events saved to database
   - Automatically broadcast to all connected WebSocket clients

### Event Format

**Server → Client (WebSocket):**
```json
{
  "event_type": "task_started",
  "timestamp": "2025-11-28T17:00:00",
  "task_id": 1,
  "risk_id": null,
  "details": {"message": "Task started"}
}
```

**Client → Server (WebSocket):**
```json
{
  "action": "ping"
}
```

**POST /simulations/{simulation_id}/broadcast-event/:**
```json
{
  "event_type": "simulation_started",
  "task_id": null,
  "risk_id": null,
  "details": {}
}
```

## Usage Examples

### Broadcast Event via HTTP
```bash
curl -X POST http://localhost:8001/simulations/1/broadcast-event/ \\
  -H "Content-Type: application/json" \\
  -d '{
    "event_type": "task_completed",
    "task_id": 1,
    "details": {"duration": 3.5}
  }'
```

### Connect WebSocket Client (JavaScript)
```javascript
const ws = new WebSocket('ws://localhost:8001/ws/simulations/1/events');

ws.onopen = (event) => {
  console.log('Connected to simulation 1');
  // Send subscription request
  ws.send(JSON.stringify({ action: 'subscribe_updates' }));
};

ws.onmessage = (event) => {
  const message = JSON.parse(event.data);
  console.log('Received event:', message.event_type);
};

ws.onerror = (error) => {
  console.error('WebSocket error:', error);
};

ws.onclose = () => {
  console.log('Connection closed');
};

// Send ping to keep connection alive
setInterval(() => {
  ws.send(JSON.stringify({ action: 'ping' }));
}, 30000);
```

### Connect WebSocket Client (Python)
```python
import asyncio
import websockets
import json

async def connect():
    uri = "ws://localhost:8001/ws/simulations/1/events"
    async with websockets.connect(uri) as websocket:
        # Subscribe to updates
        await websocket.send(json.dumps({"action": "subscribe_updates"}))
        
        # Listen for events
        async for message in websocket:
            event = json.loads(message)
            print(f"Event: {event['event_type']}")

asyncio.run(connect())
```
