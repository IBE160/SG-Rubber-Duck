# Story S2.1: Implement Basic Critical Path Method (CPM) Calculation

## Epic
E2: Simulation Engine & Real-time

## Description
As a backend developer,
I want to implement the Critical Path Method algorithm,
So that I can calculate project schedules, identify critical tasks, and determine minimum project duration.

## Technical Details

### CPM Algorithm Implementation
Implemented in `backend/cpm.py` with the following components:

**Core Classes:**
- `TaskInfo` - Internal task representation with schedule calculations
- `CriticalPathCalculator` - Main CPM algorithm implementation
- `CPMResult` - Output data structure with results

**Algorithm Steps:**
1. **Forward Pass** - Calculate earliest start/finish times for all tasks
2. **Backward Pass** - Calculate latest start/finish times working backwards
3. **Slack Calculation** - Determine float/slack for each task
4. **Critical Path Identification** - Tasks with zero slack form the critical path

### API Endpoint
- **POST /projects/{project_id}/calculate-cpm/** - Calculate CPM for a project

### Output Format
Returns:
- `critical_path` - Ordered list of task IDs on the critical path
- `project_duration_days` - Total project duration in days
- `start_date` - Project start date
- `end_date` - Project end date
- `task_schedules` - Per-task schedule details:
  - earliest_start, earliest_finish (calendar dates)
  - latest_start, latest_finish (calendar dates)
  - slack (days of float/flexibility)
  - on_critical_path (boolean)

## Example Request

```bash
# Create tasks with dependencies
curl -X POST http://localhost:8001/projects/1/tasks/ \\
  -H "Content-Type: application/json" \\
  -d '{
    "text": "Requirement Analysis",
    "start_date": "2025-12-01",
    "duration": 3,
    "dependencies": []
  }'

curl -X POST http://localhost:8001/projects/1/tasks/ \\
  -H "Content-Type: application/json" \\
  -d '{
    "text": "System Design",
    "start_date": "2025-12-01",
    "duration": 5,
    "dependencies": [1]
  }'

# Calculate CPM
curl -X POST http://localhost:8001/projects/1/calculate-cpm/
```
