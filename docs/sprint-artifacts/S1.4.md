# Story S1.4: Implement Task CRUD Endpoints

## Epic
E1: Backend & Data Foundations

## Description
As a frontend developer,
I want RESTful API endpoints for managing tasks within projects,
So that I can create, read, update, and delete tasks and track their progress.

## Technical Details

### Endpoints Implemented
- **POST /projects/{project_id}/tasks/** - Create a new task in a project
- **GET /projects/{project_id}/tasks/** - List all tasks in a project with pagination
- **GET /tasks/{task_id}** - Get a specific task
- **PATCH /tasks/{task_id}** - Update task details (partial updates supported)
- **DELETE /tasks/{task_id}** - Delete a task

### Request/Response Schemas
- `TaskCreate` schema for POST requests (all fields required)
- `TaskUpdate` schema for PATCH requests (all fields optional for partial updates)
- `Task` schema for responses with full task details

### Key Features
- Partial updates via PATCH with optional fields
- Support for task dependencies (stored as JSON array)
- Progress tracking (0.0 to 1.0)
- Parent/sub-task relationships
- Cost tracking per task
- Pagination support with skip/limit
- Automatic project existence validation

## Example Requests

### Create Task
```bash
curl -X POST http://localhost:8001/projects/1/tasks/ \\
  -H "Content-Type: application/json" \\
  -d '{
    "text": "Design API",
    "start_date": "2025-12-01",
    "duration": 3,
    "progress": 0.5,
    "cost": 1000,
    "dependencies": [],
    "parent": null
  }'
```

### Get Tasks in Project
```bash
curl -X GET "http://localhost:8001/projects/1/tasks/?skip=0&limit=10"
```

### Get Specific Task
```bash
curl -X GET http://localhost:8001/tasks/1
```

### Update Task (Partial)
```bash
curl -X PATCH http://localhost:8001/tasks/1 \\
  -H "Content-Type: application/json" \\
  -d '{"progress": 0.75}'
```

### Delete Task
```bash
curl -X DELETE http://localhost:8001/tasks/1
```
