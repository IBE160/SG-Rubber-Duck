# Story S1.3: Implement Project CRUD Endpoints

## Epic
E1: Backend & Data Foundations

## Description
As a frontend developer,
I want RESTful API endpoints for managing projects,
So that I can create, read, update, and delete projects from the frontend.

## Technical Details

### Endpoints Implemented
- **POST /projects/** - Create a new project
- **GET /projects/** - List all projects with pagination
- **GET /projects/{project_id}** - Get a specific project with all relationships
- **PATCH /projects/{project_id}** - Update project details
- **DELETE /projects/{project_id}** - Delete a project and cascade to all related data

### Request/Response Schemas
- Uses `ProjectCreate` schema for POST requests
- Uses `Project` schema for responses, including tasks, risks, and simulation_runs
- Proper error handling (404 for missing projects)

### Database Operations
- Full CRUD operations implemented in `crud.py`
- Automatic cascade deletion of related tasks, risks, and simulation runs
- Pagination support with `skip` and `limit` parameters

## Example Requests
```bash
# Create project
curl -X POST http://localhost:8001/projects/ \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Test Project",
    "description": "A test project",
    "budget": 10000,
    "start_date": "2025-12-01",
    "end_date": "2025-12-14"
  }'

# Get project
curl -X GET http://localhost:8001/projects/1

# Update project
curl -X PATCH http://localhost:8001/projects/1 \
  -H "Content-Type: application/json" \
  -d '{"name": "Updated Project Name"}'

# Delete project
curl -X DELETE http://localhost:8001/projects/1
```
