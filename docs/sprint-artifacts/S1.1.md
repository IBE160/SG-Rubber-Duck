# Story S1.1: Initialize FastAPI app and basic configuration

## Epic
E1: Backend & Data Foundations

## Description
As a backend developer,
I want to set up the basic FastAPI application structure and configuration,
So that I have a running server that can serve API endpoints.

## Technical Details
*   **Application Entry Point:** Create `main.py` to initialize the FastAPI app.
*   **Uvicorn:** Configure `uvicorn` as the ASGI server for local development.
*   **Basic Route:** Implement a simple root endpoint (e.g., `/` or `/health`) that returns a "Hello World" or status message.
*   **Configuration:** Set up a method for managing application settings (e.g., using Pydantic's `BaseSettings` or environment variables directly).
*   **Dependencies:** Ensure `fastapi` and `uvicorn` are installed and listed in `backend/requirements.txt`.
*   **Project Structure:** Establish initial folder structure within `backend/` for future modules (e.g., `routers`, `models`, `schemas`, `crud`).

## Acceptance Criteria
*   The FastAPI application can be started successfully using `uvicorn`.
*   Accessing the root endpoint (`/` or `/health`) via HTTP returns a successful response (e.g., 200 OK) with a basic message.
*   Key configuration settings (e.g., app title, debug mode) can be loaded from environment variables or a configuration file.
*   `requirements.txt` is updated with necessary dependencies for this story.

## Definition of Done
*   FastAPI application initialized and runnable.
*   A basic, working endpoint is accessible.
*   Configuration is set up to read from environment variables.
*   `backend/requirements.txt` updated.
*   Initial project structure is in place.

## Validation / Notes
- 2025-xx: Kjørte `PYTHONPATH=.. ./venv/bin/python -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8001` (fra backend/). Uvicorn startet OK.
- Curl-resultater:
  - `/` → 200, body `{"message":"FastAPI is running!"}`
  - `/projects/` → 404 (endpoint ikke implementert ennå i denne storyen)
  - POST `/projects/` med testpayload → 404
  - `/projects/1/tasks/` → 404
  - `/projects/1/risks/` → 404
- Konklusjon: Storyens scope (basisapp + health) oppfylt; CRUD-endepunkter er kommende arbeid i senere stories (epic E1). config.py er forenklet til dataclass (uten pydantic-settings) og leser miljøvariabler.
